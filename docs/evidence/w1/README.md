# W1 이종수 A1·B1 구성 확인 — 2026-11-09

- `sensors_unloaded.json`: 두 로봇·epick·제어기 없는 headless 월드. 27개 중 26개 토픽의 반복 수신·stamp 진행·로봇별 frame 분리 확인. 무적재 접촉 미수신으로 당시 전체 `passed=false`를 그대로 보존했다.
- `cargo_contact.json`: 별도 robot_2 월드에서 0.5 kg·0.2 m 상자를 적재판 위에 생성했다. 서로 다른 stamp의 ROS Contacts에 적재판 collision과 시험 상자 collision이 함께 기록된 것을 확인했다.
- `manifest.json`: 환경과 검사 도구·robot_2 모델의 해시.

모델·센서 관련 4개 패키지 빌드, 자산/물리 생성기 `--check`, A1 자산 8개·W1 모델 12개·B1 모의 입력 13개 검사도 통과했다.
위 두 실행은 서로 다른 조건이며 27개 토픽을 한 번에 모두 통과한 결과로 합치지 않는다.
현재 W1의 모델·물리 생성기/센서 구성 확인 범위를 마무리하며, W2 보정·동기화 완료, A3 적재 판정, 하중 성능, 정격 주기·장시간 운전·4대 부하·G1 통과를 뜻하지 않는다.

재현은 [B1 안내](../../../src/ax_perception/README.md)를 따른다. 접촉 검사는 제어기를 요구하지 않으며 시험 상자 생성·삭제만 수행한다.
