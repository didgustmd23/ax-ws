# AX_2 개발 모델 스펙

현재 URDF에서 자동 계산한 **무적재·중립 자세** 스펙이다. AX_1은 다중 흡착판(epick) 장착 기준이다.
질량·관성·속도는 시뮬레이션 가정이며 실측·제조사 정격이 아니다. 적재 정격 중량은 미확정이다.

| 항목 | 값 |
|---|---|
| 원본 모델 | `ax_2.urdf.xacro` |
| 총질량(센서·공구 포함) | 19.450000 kg |
| 전체 무게중심 XYZ (`base_link` 기준) | 0.016304, -0.000573, 0.096900 m |
| 외형 크기 XYZ (중립 자세) | 1.240000, 0.995651, 1.049174 m |
| 바퀴 반경 / 좌우 중심 간격 / 앞뒤 중심 간격 | 0.149900664 / 0.836695 / 0.671961 m |
| 최대 선속도 / 각속도 | 0.67 m/s / 0.5 rad/s |
| 최대 선가속도 | 0.67 m/s² |
| 윤거 보정 계수 | 1.1318 (기존 개발 시험값, 새 하중에서 재보정 필요) |
| 무적재 COM의 바퀴 중심 지지 영역 포함 | True |

## 전체 무게중심 기준 관성 텐서 (kg·m²)

```text
3.036485, -0.000375, 0.014382
-0.000375, 3.116508, 0.004776
0.014382, 0.004776, 4.088436
```

자세·공구·적재물 위치가 바뀌면 전체 COM과 관성도 바뀐다. 위 수치는 무적재 중립 자세에만 해당한다.
좌표는 바퀴 접지면이나 월드 원점이 아닌 `base_link` 기준이다.

## 적재부

- 적재면: [0.72, 0.72]m, 설계상 적재 높이 기준: 0.5m.
- 적재판 상면 원점: (-0.007173, -0.002966, 0.240919)m.
- 적재 높이 카메라는 제거했다. 자동 높이 측정·적재 금지 신호·허가 서비스는 현재 제공하지 않는다.
- 기존 시험 하중 0.5/1/2kg은 정격 중량이 아니다. 새 적재함에서 별도 동적 검증이 필요하다.
- 옛 상부 LiDAR 외장은 새 CAD에 없어 활성 모델에서 제외했다. 전후 LiDAR 센서는 유지한다.

센서 토픽의 robot ID는 실행 인자에 따라 바뀐다. 다중 로봇에서는 각 namespace로 분리한다.

## 갱신

`python3 tools/generate_robot_specs.py`로 두 로봇의 문서와 JSON을 함께 갱신한다.
기계 판독용 상세 관절 제한과 부품 데이터는 `src/ax_description/config/ax1_spec.json` 및 `ax2_spec.json`에 있다.
