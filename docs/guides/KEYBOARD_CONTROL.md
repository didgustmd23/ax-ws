# 키보드로 주행·팔 조종

Gazebo를 실행한 터미널은 켜 두고 새 Ubuntu 터미널을 연다.
작업 폴더에서 다음을 실행한다. `tools/keyboard_teleop.py`를 추가한 버전이 필요하다.

```bash
source /opt/ros/jazzy/setup.bash
source install/setup.bash
python3 tools/keyboard_teleop.py
```

키는 Gazebo 창이 아니라 **이 조종 터미널에 포커스를 두고** 입력한다.
기존 `ros2 topic pub` 주행 명령은 먼저 Ctrl+C로 종료한다. 조종 프로그램은 하나만 실행한다.

| 키 | 동작 |
|---|---|
| W / S | 선택한 로봇 전진 / 후진 (0.1 m/s) |
| A / D | 선택한 로봇 왼쪽 / 오른쪽 회전 (0.2 rad/s) |
| R | robot_1 ↔ robot_2 전환, 전환 시 정지 |
| 1 | 기둥 회전 선택 |
| 2 | 어깨 선택 |
| 3 | 팔꿈치 선택 |
| 4 | 손목 선택 |
| 5 | 집게 전체 회전 선택 |
| I / K | 선택한 팔 관절 + / − 0.04 rad 이동 |
| Space | 두 로봇 주행 정지 및 이 프로그램의 팔 동작 취소 |
| Q / Ctrl+C | 정지 처리 후 프로그램 종료 |

주행은 키를 누르고 있으면 키보드 반복 입력으로 이어진다. 마지막 입력 후 약 0.2초가 지나면
제로 속도를 보낸다. 최초 반복 입력 전 잠깐 멈출 수 있다. Gazebo가 느리면 화면 반영에도 지연이 있다.
팔은 robot_1에서만 가능하며 한 번에 약 2.3°씩 이동한다. 이동 완료 후 다음 입력을 받는다.
집게 전체 회전과 손가락 개폐는 다르다. Robotiq 손가락 개폐는 아직 지원하지 않는다.

팔 조작은 최신 관절 상태와 위치 한계를 확인하고, 속도·가속도 기준으로 동작 시간을 정한다.
실시간 충돌 회피나 작업 공간 장애물 검사는 제공하지 않는다. 작은 움직임으로 화면을 확인하며 조작한다.
주행과 이 프로그램의 팔 이동은 동시에 보내지 않는다. 종료 시 자신의 팔 Action을 취소하고
두 주행 제어기에 제로 속도를 보낸다. Gazebo 자체는 종료하지 않는다.
