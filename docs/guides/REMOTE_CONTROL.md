# 별도 리모컨 창으로 조종

Windows 브라우저에서 마우스로 조종하며 ROS 통신은 Ubuntu에서 실행한다.
Ubuntu 없이 실행하는 독립 시뮬레이터는 아니다. Gazebo를 먼저 실행한다.
기존 키보드 조종 프로그램과 `ros2 topic pub`는 Ctrl+C로 종료해 조종 명령이 겹치지 않게 한다.

Ubuntu의 저장소 폴더에서:

```bash
bash tools/start_remote.sh
```

Windows 브라우저에서 <http://localhost:8765>를 연다. Edge에서 이 주소를 앱으로 열면 별도 창으로 쓸 수 있다.
추가 Python 라이브러리나 빌드는 필요 없다. 기존 ROS 의존성과 빌드된 workspace는 필요하다.
서버는 이 PC의 루프백 주소에만 바인딩한다. WSL2의 localhost 전달이 작동해야 한다.

- AX_1 / AX_2 버튼: 조종 대상 선택.
- 방향 버튼: 누르고 있는 동안 주행, 놓으면 정지. 마지막 명령 후 약 0.2초에 제로 속도 전송.
- 속도 − / +: 주행·회전 속도를 함께 조절하며 현재 값을 표시.
- 관절 선택 → 이동 각도 − / + → 방향 이동: AX_1 팔을 한 단계 이동.
- 전체 정지: 두 로봇 제로 속도 + 이 리모컨이 보낸 팔 Action 취소.
- 현재 관절 각도와 연결·동작 상태를 표시한다.

창을 숨기거나 닫을 때 정지를 요청하며, 연결이 끊기면 새 주행 명령을 보내지 않는다.
서버가 클라이언트 상태 확인을 1초 이상 받지 못하면 진행 중인 팔 Action도 취소한다.
이는 실물 비상정지나 실시간 충돌 회피가 아니다. 팔 이동 속도 별도 조절과 손가락 개폐는 미지원이다.
리모컨 창은 하나만 사용한다. 서버 종료는 Ubuntu 실행 터미널에서 Ctrl+C다. Gazebo는 별도로 유지된다.
