# 별도 리모컨 창으로 조종

Windows 브라우저에서 마우스로 조종하며 ROS 통신은 Ubuntu에서 실행한다.
Ubuntu 없이 실행하는 독립 시뮬레이터는 아니다. Gazebo를 먼저 실행한다.
기존 키보드 조종 프로그램과 `ros2 topic pub`는 Ctrl+C로 종료해 조종 명령이 겹치지 않게 한다.

Ubuntu의 저장소 폴더에서:

```bash
bash tools/start_remote.sh
```

Windows 브라우저에서 <http://localhost:8765>를 연다. Edge에서 이 주소를 앱으로 열면 별도 창으로 쓸 수 있다.
추가 Python 라이브러리나 빌드는 필요 없다. 기존 ROS 의존성과 빌드된 workspace는 필요하다.
서버는 이 PC의 루프백 주소에만 바인딩한다. WSL2의 localhost 전달이 작동해야 한다.

- AX_1 / AX_2 버튼: 조종 대상 선택.
- AX_1 공구 교체: **다중 흡착판 · 12컵**(`epick`) 또는 **손가락 집게 · Robotiq 2F-85**(`robotiq`)를 선택해 하나씩 장착한다. `epick`은 호환 실행값이며 실제 EPick 제품 형상이 아니다. 현재 월드·센서·하중 등 실행 설정을 유지하며 Gazebo와 제어기를 재시작하므로 두 로봇·팔·상자도 시작 상태로 돌아간다. 교체 중 조작과 중복 요청은 차단한다. AX_2를 선택하면 교체 버튼은 비활성화된다. 초기화 버튼은 교체한 공구를 유지한다. 실물 자동 공구 교환이나 운영 중 교체 기능은 아니다.
- 방향 버튼: 한 번 클릭하면 계속 주행하며, 다른 방향을 클릭하면 전환한다. 버튼에서 손을 떼도 계속 움직인다.
- 정지 버튼 또는 스페이스: 연속 주행 종료. 현재 방향 버튼은 강조 표시된다.
- 속도 − / +: 주행·회전 속도를 함께 조절하며 현재 값을 표시.
- 주행 속도와 1회 관절 이동 각도는 숫자를 입력한 뒤 **적용** 또는 Enter로 직접 지정할 수 있다. 회전 속도도 기본값 대비 같은 비율로 바뀐다. 적용하면 정지 명령을 보내 감속하며 방향 버튼을 다시 눌러야 이동한다.
- 기본·최대 주행 속도는 0.67 m/s, 회전은 0.20 rad/s다. 최소 주행은 0.04 m/s이며 이때 회전은 약 0.012 rad/s다. 회전 제어기의 별도 상한은 0.50 rad/s다.
- 주행 가속·감속은 각각 0.67 m/s², 회전 가속·감속은 각각 0.20 rad/s²다. 기본 속도로 정지 출발하면 이론상 2초에 약 1m 이동하며, 정지는 최대 속도에서 약 1초·0.335m가 필요하다(시뮬레이션 기준).
- 관절 선택 → 이동 각도 − / + → 방향 이동: AX_1 팔을 한 단계 이동.
- 리모컨의 1회 이동 각도는 최대 90°다. 기본값은 약 2.3°를 유지하고 관절의 실제 위치 제한을 넘는 목표는 잘라낸다. 이동 속도·가속도 제한은 별도로 유지한다.
- 전체 정지: 두 로봇 제로 속도 + 이 리모컨이 보낸 팔 Action 취소.
- 전체 로봇 초기화·다시 소환: 넘어짐·끼임 복구용. 현재 월드와 공구 등 실행 인자를 유지해 Gazebo와 제어기를 다시 시작한다. 두 로봇·팔·상자도 시작 상태로 돌아간다. 리모컨 창은 유지된다. 복구 중 조작은 차단하며 완료 후 방향 버튼을 다시 눌러야 이동한다. 다른 작업 폴더의 시뮬레이션은 종료하지 않는다.
- 현재 관절 각도와 연결·동작 상태를 표시한다.

창을 숨기거나 닫을 때 정지를 요청하며, 연결이 끊기면 새 주행 명령을 보내지 않는다.
이 경우 마지막 명령 후 약 0.2초에 제로 속도를 전송한다. 다시 연결돼도 자동으로 주행을 재개하지 않는다.
로봇 변경이나 팔 조작 시에도 연속 주행을 해제한다. 팔은 기존처럼 한 번 클릭할 때 설정한 각도만큼 움직인다.
서버가 클라이언트 상태 확인을 1초 이상 받지 못하면 진행 중인 팔 Action도 취소한다.
현재 속도·가감속은 정지 출발 후 약 2초에 1m 이동하기 위한 AX 시뮬레이션 개발용 값이며 제조사 공식값이나 AX 실물 정격이 아니다. 단일 설정 기준은 `src/ax_control/config/common_controllers.yaml`이다.
이는 실물 비상정지나 실시간 충돌 회피가 아니다. 팔 이동 속도 별도 조절과 손가락 개폐는 미지원이다.
리모컨 창은 하나만 사용한다. 서버 종료는 Ubuntu 실행 터미널에서 Ctrl+C다. Gazebo는 별도로 유지된다.
