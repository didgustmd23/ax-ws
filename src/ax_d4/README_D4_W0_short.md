# D4 — 로봇 작업 상태 기록·검증 (W0)

D4는 A3에서 전달받은 `robot_1`, `robot_2`의 작업 상태를 **검사하고 DB에 기록**하는 역할을 담당함.

## 파일 구성

- **`input_source.py`**: A3의 로봇 상태 메시지를 수신해 D4 메인으로 전달함.
- **`common_contract.py`**: 메시지 형식, 로봇 번호, 실행 ID 및 결과값을 검사함.
- **`ledger.py`**: 중복·이전 상태를 확인하고 SQLite DB에 기록하며 최신 상태를 조회함.
- **`d4_main.py`**: 위 세 파일을 연결해 상태 수신 → 검사 → 기록 → 조회를 실행함.

## 현재 진행 상태

W0 기본 코드 작성 완료. **A3의 D4용 상태 발행 기능은 아직 연결 전**이므로 실제 ROS2 연동 검증은 이후 진행 예정.
