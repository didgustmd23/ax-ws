# AX 오브젝트별 분리 메시

> 이 문서는 메시 분리와 후속 연결의 이력을 함께 기록한다. 아래 첫 설명의 원본·URDF 변경 여부는 최초 분리 작업 시점 기준이다. 현재 모델은 [문서 안내](../../../../docs/README.md)를 참고한다.

원본: `../AX_1.obj`, 재질: `../AX_1.mtl`.

손가락과 집게 연결기구를 제외하고 원본 오브젝트 경계대로 분리했다. 원본 파일과 현재 URDF는 변경하지 않았다.

## 제외한 오브젝트

- `Gripper_Finger_01`
- `Gripper_Finger_02`
- `Gripper_LinkPair_01`
- `Gripper_LinkPair_02`
- `Gripper_CenterPad`

집게부 추가 분리가 필요한 범위를 보류했으며 손목 하우징 `Gripper_WristHousing`은 분리했다. 제외된 형상은 원본 OBJ에 그대로 있다.

## 파일·좌표 규칙

- 최초 오브젝트 분리는 19개 OBJ이며 대응표와 정점·면 수는 `manifest.json`에 기록했다. 이후 기둥을 추가 분리하여 현재는 21개 OBJ다. 추가 분리 내역은 `column_split_manifest.json`과 아래 원통 회전 절을 참고한다.
- 각 OBJ는 같은 폴더의 `AX_1.mtl`을 참조한다. UV, 법선, 재질 선택과 smoothing 설정을 보존했다.
- 원본 조립 좌표·방향·배율을 유지했다. 링크별 원점 이동, m 변환, 관절축 추정은 수행하지 않았다.
- 원본이 mm 단위라는 가정이 맞으면 URDF에서 `scale="0.001 0.001 0.001"`을 사용한다. 실제 제작 단위는 별도 확인한다.
- 링크별 visual origin은 메시의 원래 조립 좌표와 URDF 링크 좌표에 맞춰 보정해야 한다. 분리 파일을 바로 기존 링크에 연결하면 위치가 맞지 않을 수 있다.
- 바퀴 번호의 전후·좌우 매핑, `Arm_02_Movie`와 팔 관절의 정확한 대응은 모델링 담당자와 확인한다.
- 선반, 상자, `AX1_Right_*`도 개별 오브젝트로 추출했다. 고정 여부와 용도를 확인한 뒤 로봇 링크 또는 별도 물체에 연결한다.
- 분리 메시가 collision·관성·관절·제어기를 자동으로 생성하지는 않는다.

## URDF 경로 예시

```xml
<mesh filename="package://ax_description/meshes/parts/ax_body.obj"
      scale="0.001 0.001 0.001"/>
```

## 검증

분리된 모든 면의 정점·UV·법선 참조를 원본과 대조했다. 원본 OBJ·MTL의 SHA-256이 작업 전후 동일함을 확인했다. RViz·Gazebo 표시 및 실제 관절 제어 시험은 수행하지 않았다.

## 몸통의 URDF 연결

분리 후 첫 연결 단계로 `ax.urdf.xacro`의 `base_link` visual에 `ax_body.obj`를 적용했다. MTL 재질을 사용하도록 기존 파란색 visual 재질 지정을 제거했다.

- 배율: `0.001 0.001 0.001` (mm 단위 가정).
- 원본 몸통 경계 중심: `(3, 0, 382.77325)`.
- visual origin: `xyz="-0.003 0 -0.38277325"`, `rpy="0 0 0"`.
- 보정 후 외형 크기: 약 `1.366 × 0.774 × 0.605547 m`.
- 보정은 경계 상자의 중심을 링크 원점에 맞춘 것으로 실제 질량 중심이나 확정된 기구 원점이 아니다.
- 나머지 부품도 동일 조립 좌표 변환을 고려해 연결해야 한다. 각 부품을 개별적으로 중심 정렬하면 원래 조립 위치를 잃는다.
- collision·관성·바퀴·팔 배치는 아직 기존 개발용 설정이다. 현재 외형과 크기가 다르므로 물리 시뮬레이션 사양 확정으로 간주하지 않는다.

연결 후 패키지 빌드, Xacro 변환, `check_urdf`, 설치 경로의 OBJ·MTL 존재와 경계 중심 계산을 확인했다. GUI 외형·재질 표시는 별도 확인이 필요하다.

## 바퀴 4개의 URDF 연결

기존 +X 전방, +Y 왼쪽 기준과 mm 단위 가정을 적용했다. 바퀴 중심은 메시 경계에서 추정한 축 중심이며 실측 관절 좌표가 아니다.

| URDF 링크 | 메시 | 원본 중심 (mm) | base_link 기준 관절 위치 (m) |
|---|---|---|---|
| `front_left_wheel` | `ax_tire_02.obj` | `(440, 311, 190)` | `(0.437, 0.311, -0.19277325)` |
| `front_right_wheel` | `ax_tire_01.obj` | `(440, -311, 190)` | `(0.437, -0.311, -0.19277325)` |
| `rear_left_wheel` | `ax_tire_04.obj` | `(-440, 311, 190)` | `(-0.443, 0.311, -0.19277325)` |
| `rear_right_wheel` | `ax_tire_03.obj` | `(-440, -311, 190)` | `(-0.443, -0.311, -0.19277325)` |

- 바퀴 링크의 로컬 Z축을 회전축으로 유지하고 joint의 roll을 `-π/2`로 두어 차체 +Y축에 맞췄다.
- visual에는 반대 회전 `+π/2`와 원본 축 중심을 제거하는 이동을 적용했다. joint 값이 0이면 모든 정점이 원본 조립 좌표에 몸통 보정값을 더한 위치와 일치한다.
- 충돌 원통은 메시 최대 반경 약 196.309 mm를 감싸는 `radius=0.19631 m`, `length=0.144 m`로 근사했다. DiffDrive의 반지름·좌우 간격도 `0.19631 m`, `0.622 m`로 변경했다.
- wheel_mass는 기존 임시값 0.5 kg을 유지했고 관성 계산에는 새 원통 치수가 반영된다. 실제 질량·관성·접지 특성은 검증 대상이다.
- 바퀴 하단이 base_link보다 약 0.38908325 m 아래에 있어 Gazebo 생성 높이를 0.25 m에서 0.42 m로 변경했다. 초기 지면 여유는 충돌 원통 기준 약 0.030917 m다.
- 몸통 collision·관성, 팔·센서 배치는 아직 개발용 설정이다.

패키지 2개 빌드, Xacro·URDF 검사, 모든 바퀴 정점의 조립 좌표 일치, 축 중심·회전축, 회전 시 반경 유지와 충돌 원통 포함을 계산으로 확인했다. Gazebo 실제 회전·접지·주행 및 GUI 재질 표시는 별도로 확인해야 한다.

## 팔의 URDF 연결 (원통 추가 분리 전)

다음 5개 메시를 기존 팔 계층에 연결했다. mm 단위 가정과 몸통 보정값 `(-0.003, 0, -0.38277325) m`를 공통 적용한다.

| 링크 | 메시 | 원본 기준 링크 원점 (m) | 관절축 |
|---|---|---|---|
| `arm_mount_link` | `arm_01_fixed.obj` | `(0.180, 0.185, 0.612)` | 고정 |
| `arm_rotating_base_link` | `arm_02_movie.obj` | `(0.180, 0.185, 1.500)` | Z |
| `upper_arm_link` | `arm_03_upperarm.obj` | `(0.240, 0.185, 1.600)` | X |
| `forearm_link` | `arm_04_forearm.obj` | `(0.372, 0.185, 2.160)` | X |
| `wrist_link` | `gripper_wristhousing.obj` | `(0.462, 0.640, 1.720)` | X |

- 원점과 축은 원형 연결부·조립 형상에서 추정한 시각 검토용 값이다. 실제 CAD 관절 정의는 아니며 모델링 담당자 확인이 필요하다.
- 모든 팔 관절이 0일 때 원본 조립 자세를 재현한다. 기존 기본 도형 모델의 0각 자세와 다르다.
- 각 visual에는 해당 원본 기준 링크 원점을 빼는 이동을 적용했다. 부모-자식 joint 이동은 원점의 차이로 설정하여 상위 관절 회전이 하위 링크에 전달된다.
- 기존 어깨·팔꿈치·손목의 Y축을 X축으로 바꿨다. 기존 IK·목표각·pose는 새 기구 기준으로 재검증해야 한다.
- 팔 충돌 형상은 각 메시의 경계 상자로 근사했다. 비스듬한 전완 등은 빈 공간도 포함하므로 정밀 충돌·접촉 검증에 그대로 사용하지 않는다.
- 관성은 경계 상자와 기존 임시 질량으로 계산했다. 질량·무게중심·토크·이득·가동 범위는 실제 사양이 아니다. Gazebo 동적 검증은 별도다.
- 손목 하우징 내부의 가동부는 분리하지 않았다. 전체 하우징은 `wrist_link`와 함께 움직인다.
- 기존 임시 집게·손가락은 손목 하단의 원본 좌표 `(0.462, 0.640, 1.446) m`로 옮기고 로컬 +X가 아래쪽을 향하도록 연결했다. 실제 손가락·중앙 패드·링크 쌍 메시의 연결은 보류 상태다.
- 몸통과 바퀴, 손가락 링크·손가락 자체 관절 정의는 이번 연결에서 변경하지 않았다. 센서는 기존 임시 위치다.

패키지 빌드, Xacro·URDF 검사, 5개 팔 메시의 원본 조립 좌표 재현, 충돌 상자 포함, 양의 관성, 관절별 회전 시 상위 링크 고정·하위 링크 이동을 계산으로 확인했다. [계산 검증 결과](../../../../docs/evidence/model/arm_mesh_mount/geometry_checks.json)를 참고한다. GUI·Gazebo 실제 동작·자기 충돌·파지는 검증하지 않았다.

## 고정 받침·회전 원통 분리 (현재 구조)

사용자가 원통을 받침과 독립적으로 회전하도록 지정하여 `arm_01_fixed.obj`를 추가 분리했다. 기존 파일은 보존했다.

| 파일 | 구성 | URDF 링크 |
|---|---|---|
| `arm_01_support.obj` | 하단 받침, 외측 지지대·브래킷·볼트 등 | `arm_mount_link` (고정) |
| `arm_01_column.obj` | 중앙 원통 표면과 원통 둘레의 3개 링 | `column_link` (Z축 회전) |

- 원본 정점 위치를 기준으로 면 연결 성분 20개를 구분하고 중앙 원통·동심 링 4개 성분을 회전부에 배정했다. 분리 방식은 형상 기반이며 링의 실제 기구 귀속은 모델링 담당자 확인이 필요하다.
- 고정부 1,776면 + 원통부 800면 = 원본 2,576면이다. 각 면은 정확히 한 결과 파일에 배정했다. 모든 면의 정점·UV·법선 참조를 원본과 대조했다.
- 원통 원점은 원본 좌표 `(0.180, 0.185, 0.780) m`다. `arm_mount_link → column_link`는 `(0, 0, 0.168) m`, 축은 `(0, 0, 1)`이다.
- 새 관절 이름은 `column_yaw_joint`이며 임시 범위는 ±3.14159 rad, 속도는 0.5 rad/s, effort는 10 N·m다. 실제 가동 범위·토크·속도는 미확정이다.
- 원통 상단의 부품은 `arm_upper_mount_joint`로 고정 연결했다. 부모는 `column_link`, 원점은 `(0, 0, 0.72) m`다. 중복된 상단 `arm_yaw_joint`와 명령 브리지·Gazebo 제어기는 제거하여 팔 수평 회전을 `column_yaw_joint` 하나로 통일했다.
- 원통 관절을 돌리면 `column_link`와 위쪽 팔·기존 임시 집게가 함께 회전하고 하단 받침·외측 지지 구조·몸통·바퀴는 고정된다.
- 원통 충돌은 반지름 0.104 m, 길이 0.72 m의 원통으로 근사했다. 기존 전체 임시 질량 1 kg을 고정부 0.6 kg·원통부 0.4 kg으로 배분했으며 실측 질량이 아니다.
- ROS `/column_yaw/command`의 `std_msgs/msg/Float64` 값(rad)을 Gazebo `/model/ax/column_yaw_joint/position`으로 전달하는 브리지와 위치 제어기를 추가했다.
- `display.launch.py`의 관절 GUI에서 `column_yaw_joint`로 확인한다. Gazebo 사용 시 해당 GUI는 실제 상태 피드백이 아니므로 별도 실행한다.

최초 분리 시 패키지 2개 빌드·Xacro·URDF 검사, 원본 링크들의 0각 변환 보존, ±0.5 rad·π/2 회전에서 고정부 정지·원통과 하위 팔 회전, 충돌 형상 포함·관성·질량 합을 계산으로 확인했다. [최초 검증 결과](../../../../docs/evidence/model/column_yaw/geometry_checks.json)는 상단 회전을 별도로 두었던 시점의 기록이다.

이후 수평 회전 중복을 제거하여 상단 연결을 고정했다. 빌드·URDF 검사와 0, ±0.5 rad, π/2에서 모든 링크 자세 보존 및 원통-상단 부품 사이 상대 자세 고정을 확인했다. [단일 회전 검증 결과](../../../../docs/evidence/model/single_column_yaw/geometry_checks.json). `verify_handoff.py`의 명령 채널도 `/column_yaw/command`로 맞추고 X축 팔 관절에 맞게 각도 측정 축을 갱신했다. 실제 GUI·Gazebo 동작과 접촉·자기 충돌은 아직 검증하지 않았다.

### 고정부·원통 구분 색상

- 고정 받침·외측 지지 구조: 짙은 회색, RGB `(0.22, 0.25, 0.30)`.
- 회전 원통·링: 주황색, RGB `(1.0, 0.45, 0.05)`.
- 두 파생 OBJ의 재질 참조를 `ax_column_colors.mtl`로 바꾸고 URDF visual에도 같은 색상을 지정했다. 형상·관절·원본 `AX_1.mtl`은 변경하지 않았다.
- 최초 분리 시의 재질 보존 설명과 달리 이 두 파생 메시에는 사용자가 요청한 구분 색상을 적용했다. RViz·Gazebo를 재시작해 표시를 확인한다.
