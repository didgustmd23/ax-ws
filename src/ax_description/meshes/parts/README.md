# 로봇별 분리 메시

현재 `AX_1.obj`, `AX_2.obj`, `AX_Box.obj`를 오브젝트 경계대로 분리한다. 원본 OBJ·MTL은 수정하지 않는다.

| 폴더 | 원본 | 결과 | 사용 범위 |
|---|---|---|---|
| `AX_1/` | `../../AX_1.obj` | 원본 18개 + 받침·기둥 파생 2개 | 현재 `ax.urdf.xacro`의 차체·바퀴·팔 |
| `AX_2/` | `../../AX_2.obj` | 원본 8개 | `ax_2.urdf.xacro`·별도 생성 물리 특성·센서에 연결 |
| `boxes/` | `../../AX_Box.obj` | 상자 5개 | 독립 물체 자산; 로봇 링크에 미연결 |

표의 원본 경로는 각 하위 폴더 기준이다. 이전 평면 구조의 파츠는 위 구조로 교체했다. 이전 AX_1에 있던 선반은 현재 AX_1 원본에 없으며, AX_2 선반은 `AX_2/ax_shelf.obj`다.

## 재생성

저장소 루트에서 다음을 실행한다. 스크립트는 실행 위치에 의존하지 않는다.

```bash
python3 tools/split_robot_meshes.py
python3 tools/sim/ax_regen_physics.py check
# 생성 결과 교체가 필요할 때만 명시적으로 실행
python3 tools/sim/ax_regen_physics.py regen
python3 -m unittest discover -s tools/tests -v
```

`split_robot_meshes.py --output-dir /tmp/ax_mesh_parts`로 별도 폴더에도 생성할 수 있다. 각 폴더의 `manifest.json`에 원본·재질 SHA-256, 오브젝트 대응, 정점·UV·법선·면 수와 출력 해시를 기록한다. 원본 오브젝트를 제거·개명할 때에는 이전 manifest와 대조하여 더 이상 생성하지 않는 파츠를 별도로 정리해야 한다.

## 좌표·재질 규칙

- 조립 좌표·방향·배율을 유지하고 링크별 중심 정렬은 하지 않는다. 원본은 mm로 가정하며 URDF visual에 `scale="0.001 0.001 0.001"`을 적용한다.
- 면의 정점·UV·법선 참조를 로컬 인덱스로 다시 매긴다. 원본 오브젝트별 면 순서·재질 선택·smoothing을 보존한다.
- OBJ가 참조하는 원본 MTL을 같은 폴더에 복사한다. 원본 MTL은 변경하지 않는다.
- AX_1 손가락·패드·링크 쌍도 모두 추출하되, 현재 URDF 집게에는 손목 하우징만 사용한다. 메시 분할은 가동부 관절 연결이나 파지 구현을 뜻하지 않는다.
- AX_2는 원본의 장면상 이동·회전·배율을 그대로 보존한다. 분할 도구 자체는 로봇별 원점·관절·질량을 정의하지 않는다. 현재 AX_2의 모델 원점 보정·관절·독립 질량 특성은 Xacro와 물리 생성기가 별도로 적용한다.

## AX_1 받침·회전 기둥

`AX_1/arm_01_fixed.obj`는 전체 원본 파츠로 남겨 두고, 같은 폴더에 두 파생 파츠를 만든다.

| 파일 | 구성 | URDF 링크 | 표시 색상 |
|---|---|---|---|
| `arm_01_support.obj` | 하단 받침·외측 지지대·브래킷·볼트 | `arm_mount_link` | 짙은 회색 |
| `arm_01_column.obj` | 중앙 원통 표면과 동심 링 3개 | `column_link` | 주황색 |

좌표가 같은 정점을 연결하여 면 연결 성분 20개를 구분하고, 기존 XY 경계 기준으로 중앙 원통과 링 4개 성분을 회전부에 배정한다. 받침 1,776면 + 회전부 800면 = 원본 2,576면이며, 모든 면은 한 파생 파츠에만 배정된다. 형상 기반 구분이며 링의 실제 기구 귀속은 미확정이다. 두 파생 OBJ만 `ax_column_colors.mtl`로 재질을 바꿔 기존 구분 색상을 유지한다.

상세 분류와 출처 해시는 `AX_1/column_split_manifest.json`에 기록한다.

새 원본의 원통은 Z=780~1346.6586 mm이며 상단 팔 베이스 기준점은 Z=1355.3438 mm다. 이 차이는 원본 조립 형상에 포함된다. `column_yaw_joint`의 축 원점 `(180, 185, 780) mm`는 유지하며, 상단 fixed 연결은 Z=575.3438 mm, 어깨 상대 위치는 `(114.4427, 0, 100) mm`로 맞췄다. 축과 기준점은 형상 추정값이다.

팔 조립체는 `arm_mount_joint`를 `xyz="0 0 0.22922675"`로 두어 기둥 회전축을 차체 `base_link`의 X/Y 중심에 배치한다. 원본 조립 위치 대비 X=-177 mm, Y=-185 mm 이동하며 높이·팔 내부 상대 배치·visual의 CAD 원점 보정은 유지한다. 원본 OBJ 정점은 이동하지 않는다.

URDF visual 보정·관절 원점·생성기의 링크 기준점을 함께 갱신했다. 질량 예산은 유지하고 짧아진 원통의 가상 튜브 길이·COM·관성 및 충돌 상자를 다시 계산한다. 현재 수치는 `config/physical_properties.json`이 기준이며, 이전 모델의 증거·COM 그림은 현재 형상의 검증 근거가 아니다.

## 검증 범위

단위 테스트는 원본 전체 면의 정점·UV·법선·재질·smoothing 대조, 인덱스 변환, 파생 기둥의 면 보존과 manifest 해시를 검사한다. 메시·재질 경로, Xacro·URDF·충돌 포함·물리 특성은 모델 검사 대상이다. GUI의 재질 표시, Gazebo 접촉·주행·파지·동적 안정성은 별도로 확인해야 한다.
